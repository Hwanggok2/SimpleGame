- 흰색 점선 조준선, 테두리형 가로 타원 끝점과 알파 0.5 붉은 명령 화살표
- 카드 리롤에서 이미 제시된 카드가 다시 나오는 문제 수정
- 자동 공격 On/Off, 시작 전 쉬움·보통 난이도 선택과 `StageSpawnEasy` 추가
- 기존 조작을 모드 2로 유지하고 직접 이동·자동 조준 방식의 모드 1 추가
- 자동 공격 반복 간격을 0.5초에서 0.3초로 변경
- 카드 등급 재분류와 융합 스킬 3종 추가
- 융합 재료가 사라진 뒤 1레벨부터 다시 등장하는 성장 순환 구현
- 기획서, 기능 정의서, 밸런스 워크북과 Unity 생성 데이터 동기화
- 스킬·스테이지·난이도·설정 화면 설명 문구를 `GameString` 121행으로 데이터화하고 런타임 키 조회로 전환
- 설정 기본 정보 화면, 3가지 조작 모드, 적용 전 pending 편집, 패드 자유 Drag와 Player 프리팹 체력 바 추가

## 2. 직전 작업 확인 및 보완

- 조준 중인 흰색 점선·테두리 타원과 확정 명령의 붉은 화살표를 독립 표시한다.
- 새 명령을 내리면 이전 화살표를 남기지 않고 새 목적지로 옮기며, 도착·명령 취소 시 숨긴다.
- 한 카드 선택 화면에서 처음 제시된 카드와 모든 리롤 결과를 이력으로 유지해 이미 본 카드 ID를 다시 뽑지 않는다.
- Pause에 자동 공격 토글을 두고 로컬 조작 설정과 함께 저장한다.
- 시작 전 난이도 선택 상태에서 시간을 멈추고, 기존 `StageSpawn`은 보통, `StageSpawnEasy`는 쉬움으로 사용한다.
- 위 내용이 `GameDesignDocument.md` 21장과 `FunctionalSpecification.md` 27장에 보존돼 있음을 확인했다.

## 3. 조작 모드와 자동 공격

- 기본·구버전 호환 모드는 모드 2다. 좌측 패드로 조준하고 우측 `공격` 버튼으로 이동·공격 명령을 확정한다.
- 모드 1은 좌측 패드 방향과 세기에 비례해 직접 이동한다.
- 모드 1 우측 `자동 조준` 버튼은 현재 화면 안에서 Player와 가장 가까운 살아 있는 Enemy를 잠근다.
- 수동 패드 입력이 자동 접근보다 우선하며, 패드를 놓으면 살아 있는 잠금 대상 추적을 재개한다.
- 자동 공격 On이면 모드 1 수동 이동 중에도 사거리 내 최근접 Enemy를 이동을 끊지 않고 0.3초마다 공격한다.
- 자동 공격 Off에서도 우측 버튼으로 잠근 대상에는 접근 후 정확히 한 번 공격하고 잠금 표시만 유지한다.
- 반복 명령 대상이 사망하거나 풀 세대가 바뀌거나 자동 공격을 Off로 바꾸면 자동 반복 명령을 즉시 취소한다.
- 설정 `적용/기본값`, 모드별 버튼 문구, v1 설정의 v2 마이그레이션을 추가했다. 하위 화면 복귀는 pending 값을 유지하고 Pause 전체 종료만 미적용값을 폐기한다.

## 4. 융합 스킬과 카드 등급

카드 등급은 `일반 / 희귀 / 에픽 / 레전더리` 네 단계로 정리했다.

| 분류 | 등급 |
|---|---|
| 치명타·체력·이동 속도·공격 범위 | 일반 |
| 관통·정전기·오물 투척·이기어검·참격·흡혈·방패 우회 | 희귀 |
| 절단 | 에픽 |
| 융합 스킬 | 레전더리 |

융합 카드는 모든 재료가 마스터일 때 가중치 10으로 등장하며 같은 융합은 한 실행에서 한 번만 획득한다.

| 융합 | 재료 | 효과 |
|---|---|---|
| 이기어검·관통 | 이기어검 수 3, 타격 수 3, 관통 5 | 비행 전체 경로에서 생성 개체당 한 번, 적중 수 제한 없이 관통 |
| 이기어검·정전기 | 이기어검 수 3, 타격 수 3, 정전기 5 | 각 검 적중을 중심으로 마스터 정전기 독립 발동 |
| 정전기·오물 투척 | 정전기 5, 오물 투척 5 | 각 장판에서 Enemy 세대별 첫 피해에만 마스터 정전기 발동 |

- 융합 선택 시 재료 카드 스택과 실제 기본 스킬 레벨을 0으로 만든다.
- 사라진 재료는 다음 레벨업부터 1레벨 카드로 다시 등장한다.
- 재획득 기본 스킬과 이미 얻은 융합은 서로 독립된 공격 흐름을 유지한다.
- 재료를 다시 마스터하면 아직 얻지 않은 다른 융합의 조건으로 사용할 수 있다.

## 5. 발견한 문제와 해결

- 같은 화면의 리롤 이력이 현재 세 장으로만 제한돼 이전 카드가 다시 등장하던 문제를 전체 제시 이력으로 수정했다.
- 모드 1 자동 조준 버튼을 접근 중 연타하면 공격 예약이 누적되던 문제를 잠금 명령당 1회로 고정했다.
- 자동 공격을 Off로 바꿔도 이미 자동 발행된 접근 명령이 한 번 더 공격하던 문제를 자동 반복 명령만 식별해 취소하도록 수정했다.
- 모드 2 반복 대상의 사망·풀 세대 변경 뒤 일반 경로 Enemy로 명령이 이어질 수 있는 순서를 반복 대상 유효성 우선 검사로 수정했다.
- 구버전 설정 JSON은 크기·위치·토글 값을 보존하고 모드 2로 마이그레이션한다.
- 융합 카드를 다른 융합의 재료로 참조하는 잘못된 Excel 데이터는 Import 오류로 차단한다.

### 6.1 GameString 문자열 데이터화

- `GameString` 시트를 헤더 제외 121개 데이터 행으로 구성하고 필수 컬럼을 `StringId`, `KoKR`로 정했다. 그 밖의 컬럼은 Import 대상에서 제외한다.
- `LevelUpCard`는 이름과 설명 원문 대신 `NameKey`, `DescriptionKey`로 `GameString`을 참조한다. 기존 직렬화 문구는 구버전 데이터와 조회 실패를 위한 fallback으로 유지한다.
- Importer는 `GameStringTable` ScriptableObject를 생성하고 `GameDataManifest`에 연결한다.
- 런타임은 `StringComparer.Ordinal` Dictionary를 최초 조회 시 구성하며, `GameString` 값 → 호출자 fallback → `[StringId]` 순으로 표시한다.
- `{0}`, `{1}` 형식 인자를 지원하고 형식 적용 실패 시 fallback 템플릿을 우선 사용한다.
- `KoKR` 문구를 수정한 뒤 데이터만 다시 Import하면 다음 실행 또는 표시 시점에 반영된다. 문구 변경을 위해 UI 프리팹을 다시 생성할 필요는 없다.
- 현재 생성 데이터는 ScriptableObject를 유지한다. Unity 빌드에는 직렬화 데이터로 패킹되며, `.bytes`는 별도 바이너리 스키마·파서·버전 관리·오류 복구가 필요하므로 측정된 로딩 병목이나 원격 패치·지연 로딩 요구가 생길 때 검토한다.
- 이번 내용을 `GameDesignDocument.md` 23장과 `FunctionalSpecification.md` 29장에 반영했다.

## 9. 설정 화면·조작 편집 UI 추가 작업

- 설정 기본 화면을 `Player 정보 / 계정 정보 / 현재 스탯 / 획득한 스킬` 네 영역으로 분리했다.
- Player 정보에는 현재 레벨, 난이도, 점수, 생존 시간을 표시한다.
- 계정 정보에는 현재 계정 레벨, 이번 게임 획득 경험치, 다음 계정 레벨 진행도를 우측 상단 정렬로 표시한다.
- 획득한 스킬에는 스탯 강화 카드를 포함한 현재 보유 카드 전체를 일반→희귀→에픽→레전더리 순으로 표시하고 같은 등급은 시트 순서를 유지한다.
- 시간, 경험치 바와 하단 안내는 Pause Overlay 아래에 남겨 어둡게 보이도록 했다.
- 조작 화면에서는 상단 설정 버튼을 흐리게 비활성화하고, 같은 `조작` 버튼으로 기본 설정 화면에 돌아오도록 했다.
- 자동 공격을 파란 On/우측 Knob와 회색 Off/좌측 Knob 상태가 분명한 스위치로 변경했다.
- `모드 1 / 모드 2 / 숨기기` 3버튼을 추가했다. 숨기기는 좌우 패드를 감추고 월드 직접 터치는 유지하며 마지막 적용 좌표와 모드를 보존한다.
- 네 개의 위치 Slider를 제거하고 실제 좌우 Control을 화면 안전 영역 전체로 직접 Drag해 배치하도록 변경했다. 어느 Control도 반대편 끝까지 이동할 수 있다.
- 조작 하위 화면을 나갔다 다시 열면 pending 편집값을 유지하고, `적용` 전에는 runtime과 PlayerPrefs를 바꾸지 않는다. Pause 전체를 닫을 때만 pending 값을 폐기한다.
- 기존 HUD 체력 숫자를 제거하고 Player 프리팹 하단에 숫자 없는 World Space 체력 비율 바를 상시 표시한다.
