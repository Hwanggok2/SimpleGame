## 2. 카드 크기와 배치

기준 해상도는 `1080×1920`이며 카드도 같은 가로:세로 비율을 사용한다.

- 카드 폭: `W=300`
- 카드 높이: `H=W×1920/1080=533.33`
- 카드 간 가로 간격: 30
- 카드 X 위치: 20, 350, 680
- 카드 Y 위치: -70
- 카드 패널 가로 Anchor: 0.04~0.96
- 카드 패널 세로 Anchor: 0.30~0.70

세 카드가 차지하는 너비는 `300×3+30×2=960`이다. 기준 해상도 1080에서 좌우 여백을 남기면서 서로 겹치지 않는다.

## 3. 텍스트 데이터 바인딩

카드 표시 데이터는 문자열 한 덩어리가 아니라 다음 필드로 전달한다.

| 프리팹 요소 | 데이터 |
|---|---|
| `LevelUpCard_In/Label` | `DisplayName`, `Rarity`, 획득 후 레벨 |
| `Panel/Skill_Text` | Excel `LevelUpCard.Description` |

`Skill_Text`는 시트에 작성한 설명을 임의로 축약하거나 재작성하지 않고 그대로 표시한다. 긴 설명은 14~20 범위의 TMP 자동 크기 조절로 대응한다. 밝은 설명 패널과 구분되도록 글자는 진한 중성색 `(0.16, 0.18, 0.21, 1)`을 사용한다.

## 4. 등급 시각화

안쪽 `LevelUpCard_In`의 사용자가 지정한 색은 변경하지 않는다. 바깥 `LevelUpCard` Image를 프레임으로 사용한다.

| 등급 | 프레임 계열 | 용도 |
|---|---|---|
| 일반 | 청회색 | 과도한 강조 없이 기본 카드 표시 |
| 희귀 | 파랑 | 차가운 고채도 강조 |
| 영웅 | 보라 | 희귀보다 높은 시각적 위계 |
| 전설 | 금색 | 최상위 확장 등급 대비 |

프레임에는 다음 효과를 적용한다.

- `Outline`: 프레임과 같은 등급색, 거리 `(3,-3)`
- `Shadow`: 프레임과 같은 등급색, 거리 `(0,-7)`
- Glow 알파는 `Time.unscaledTime`을 사용해 천천히 맥동한다.
- 카드 선택 중 `TimeScale=0`이어도 발광은 유지된다.
- 일반 등급은 발광 강도를 낮게, 희귀·영웅·전설 순으로 높인다.

별도 셰이더나 후처리를 추가하지 않고 Unity UI 기본 Mesh Effect를 사용한다. Canvas 카드 3장 규모에서는 배치와 유지보수가 단순하고 성능 비용도 작다.

## 5. 입력 구조

카드 입력은 루트 `LevelUpCard`의 Button 하나만 처리한다. `LevelUpCard_In`의 중복 Button은 제거하고 내부 Graphic의 Raycast Target을 끈다.

이 구조는 내부 이미지나 텍스트가 루트 카드 클릭을 가로채는 문제를 방지한다.

## 6. 프리팹 보존 규칙

`PrototypeSceneBuilder`는 기존 `LevelUpCard.prefab`을 새 기본 버튼으로 덮어쓰지 않는다. 사용자가 편집한 계층과 `LevelUpCard_In` 색을 유지하면서 다음 항목만 보정한다.

- 루트 크기와 Anchor
- 필수 컴포넌트 참조
- 등급 Outline과 Glow
- TMP 자동 크기 범위
- 설명 글자 대비색
- 중복 Button과 Raycast 설정

## 7. 완료 조건

- 카드 크기가 `300×533.33`이다.
- `Skill_Text`가 Excel 설명과 일치한다.
- `LevelUpCard_In` 색이 사용자 설정값으로 유지된다.
- 일반·희귀·영웅 카드 프레임이 서로 다른 색을 사용한다.
- 카드 선택 화면이 정지된 동안에도 Glow가 움직인다.
- 세 카드가 겹치지 않고 모두 루트 Button으로 선택된다.
- 빌드와 EditMode 테스트가 통과한다.
